# 高刷新率界面优化记录

本轮针对“整体卡顿”和 300Hz 屏幕反馈，保留液态玻璃材质与已有动画，减少动画、输入和聊天更新中的同步工作。基线为 `58e3185` 的 1.9.2 正式 renderer；结果为本轮工作区代码构建出的正式 renderer。

## 修改及原因

| 范围 | 修改前 | 修改后 | 原因 |
| --- | --- | --- | --- |
| 玻璃折射贴图 | 每个动画中间尺寸都计算像素并同步 `toDataURL()` 编码 | 尺寸稳定 100ms 后生成，计算与 PNG 编码交给共享 Worker；24 项 LRU 与并发去重 | 避免像素循环、同步编码占用界面线程 |
| Worker 回退 | 没有异步回退 | 不可用时按约 0.75ms 预算让出线程，使用异步 `toBlob()` | 受限环境仍保留折射效果，避免恢复原来的长同步工作 |
| 玻璃鼠标光晕 | 每次指针事件读布局并移动渐变中心 | 每个显示帧处理最新坐标，以 `translate3d` 移动固定尺寸的光晕；仅活动时保留合成提示 | 降低高回报率鼠标带来的读布局与重绘次数 |
| 侧边栏及终端 | 宽度动画每次中间网格都 fit、再次测量并调整远端 PTY | 保留原宽度动画，动画结束 fit 一次，直接读取最终网格；处理反向、取消、拖动和卸载 | 避免反复终端重排和远端尺寸请求 |
| 聊天 Markdown | 草稿或流式更新时重复解析全部可见历史 | 按消息块缓存当前文本及 HTML；最多 512 项、约 2Mi 字符；流更新仅替换变化的块 | 输入时减少与当前操作无关的历史解析，保持输出一致 |
| 共享 Tooltip | 长期开启 body 子树观察，响应玻璃样式和流式文字变化 | 仅在显示期间观察触发器及祖先，相关检查合并至一帧 | 消除无关 DOM 变化触发的几何读取 |

300Hz 的单帧预算约为 3.33ms。帧调度使用 `requestAnimationFrame`，未增加 60/120Hz 固定上限。普通 Electron 窗口的刷新由 Chromium 与系统合成器调度，未使用只针对离屏窗口的 `setFrameRate()` 作为产品设置。

侧边栏仍有逐帧宽度布局。取舍是约 220ms 动画期间保留旧终端网格，结束再匹配最终容器；快速反向回到原宽度可以无需发出尺寸请求。它可能短暂裁切旧网格或留下空白，最终尺寸必须正确。玻璃在尺寸变化时拉伸已有光学贴图，停止后更新为精确尺寸。

## 300Hz 屏幕上的正式构建对比

同一台 Windows 机器，2560×1600、300Hz 的物理显示器，普通可见 Electron 窗口、实际 main/preload 与 `file:` 正式 renderer。使用独立本地配置，SSH 由本地 fixture 提供，无外部网络请求。视口为 1440×900，每个场景连续切换侧边栏 8 次，间隔 300ms，最后等待 400ms；各场景总采样约 2.82 秒。

基线及改后均记录到 GPU compositing / rasterization 为 enabled，没有添加强制 GPU、关闭垂直同步或忽略 GPU 黑名单的启动参数。可见窗口测量前后没有同时运行其他界面测试。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 欢迎页同步 PNG 编码 | 144 次 / 912ms | 0 次 / 0ms |
| 欢迎页脚本耗时 | 1,025ms | 36ms |
| 欢迎页主线程任务耗时 | 1,477ms | 584ms |
| 终端页同步 PNG 编码 | 136 次 / 522ms | 0 次 / 0ms |
| 终端页脚本耗时 | 994ms | 92ms |
| 终端页主线程任务耗时 | 1,553ms | 828ms |
| 终端页 PTY 尺寸请求 | 88 次 | 8 次 |
| 欢迎页 rAF 间隔中位数 / P95 | 3.4ms / 10.1ms | 3.4ms / 10.0ms |
| 终端页 rAF 间隔中位数 / P95 | 3.4ms / 13.3ms | 3.4ms / 10.0ms |

欢迎页与终端页脚本工作分别减少约 96% 和 91%。同步编码为零表示编码离开界面线程，不表示取消了玻璃纹理；两页仍分别有 4 个、3 个 SVG 折射表面。

这些数据证明重复计算减少，不代表全程 300 FPS。rAF 测量的是界面线程回调节奏，不是每个 GPU 帧实际呈现的证明。改后仍出现约 10ms 的 P95 间隔，欢迎页最大间隔仍约 33ms。设置页一秒滚动采样为 206→226 个回调，但脚本耗时 19→26ms，不能据此宣称设置页 CPU 性能提高。离屏与隐藏窗口的诊断报告不作为物理 300Hz 对比依据。

## 功能与实现验证

- 桌面单元测试 **267/267**，Vue 类型检查通过，正式 Vite renderer 构建通过。
- 桌面 `src`、`electron`、`scripts` lint 为 **0 errors / 464 warnings**，并非无警告；玻璃新增与修改文件定向 lint 无错误和警告。
- 原始玻璃 SFC 开发专项 **24/24**：连续尺寸变化期间没有中间纹理生成，稳定后生成一次；250 次指针事件只有 3 次样式修改；隐藏、inert、关闭折射、半径改变、卸载清理和 Worker 失败回退通过。7 种尺寸的原始 / 新版光学像素逐字节一致。
- 正式 `file:` renderer 玻璃专项 **7/7**：CDP 确认独立 Worker target，两次未缓存几何请求成功收到真实 Worker 的 PNG 消息，同时界面线程的 `toBlob()` 与 `toDataURL()` 调用均为 0，4 个 SVG 折射表面保持。该项区别于仅凭最终显示正常推断 Worker 生效。
- 聊天源码专项 **12/12**：100 条消息、200 块历史，24 次草稿更新没有重新解析，24 次流更新仅解析当前块 24 次，历史 HTML 与阅读位置保持。
- 正式 renderer 聊天 DOM **32/32**、Tooltip **58/58**；源码完整聊天行为 **60/60**。覆盖输入法、草稿、窄屏、折叠、工具操作、停止、长代码和表格、亮暗主题与减少动态效果。
- 正式 renderer 侧边栏专项 **85/85**、7 张截图：8 次完整切换仅 8 次 PTY resize，均在 stable；8 次快速反转回到原网格为 0 次 resize。覆盖拖动、760px 抽屉、焦点 / inert、关闭动画、终端恢复及最终网格。
- 正式 renderer 全界面回归 **381/381**、123 张截图：覆盖路由、设置章节、亮暗及宽窄视口，实际鼠标命中、菜单、表单、弹层、通知、终端与传输界面。上述最终 UI 运行报告均无页面错误和外部请求。

以上 UI 运行检查使用真实 Vue 组件与 Electron；涉及消息、SSH 状态的场景使用本地 fixture。缓存解析计数与完整注入聊天场景是源码检查，不冒充正式 renderer 测试。没有据此重新验收真实 SSH/SFTP、模型网络、安装程序或其他操作系统。

## 评审结论

**Approve：** 本轮已验证的重复计算优化可以保留，视觉与动画交互按上述范围回归。持续宽度动画属于明确记录的布局成本取舍；不能把当前结果标记为全场景稳定 300 FPS。
