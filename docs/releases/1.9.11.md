# 1.9.11 升级说明

1.9.11 汇总文件传输、SSH 服务器身份、更新器和日志保护修复。从 [GitHub Release](https://github.com/aides-hik/AI-ssh/releases/tag/v1.9.11) 下载对应平台安装包，完整变更见 [更新日志](../../CHANGELOG.md)。

## SSH 指纹

- 升级前保存的连接若尚无本机信任记录，首次测试或连接时会要求核对 SHA256 指纹。请通过服务器控制台或管理员提供的信息核对后再确认。
- 信任按规范化地址及端口保存在本机；实际认证仍固定同一公钥。密钥发生变化会阻断当前连接，核对并重置信任后需要重新连接。
- 测试与正式连接使用相同规则；提前断开或终端初始化超时不再被迟到回调恢复成连接成功。

## 文件传输

- 入队时固定目标主机、目录和文件；浏览别的目录或标签不改变这些目标。
- 上传和下载先写临时文件，校验后再提交。覆盖已有文件需要确认；不支持安全提交或覆盖的文件系统会拒绝操作并保留原目标，不会先删除原文件。
- 提交开始前可以取消；进入最终提交后须等待真实结果。若提示无法确认远端替换结果，请刷新并核对后再决定是否重试。
- 取消全部操作会作废尚在准备的选择、拖拽和扫描；失败及取消记录保留，下载不自动重试不确定结果。同一路径任务分别显示自己的进度。
- Windows 不能安全表示的远端文件名会明确拒绝，不会静默改名或解释为子路径、设备或备用数据流。

## 应用更新

下载显示大小、速度和进度；未知总量使用不定进度，下载停滞时速度归零。初始化与后台下载不会阻塞设置和快捷键；取消、失败、重试或卸载订阅不会复用旧通知。

Windows 安装程序及 AppImage 启动安装流程；DMG 和 DEB 则打开系统处理入口，需按系统提示完成安装，客户端保持可操作。打开或启动失败可重新尝试，不将“已打开”当作“已升级”。

## 验证与资料

使用模拟服务、独立配置和真实本地文件系统验证异常与取消边界；SSH 回归使用本机临时服务，不访问用户服务器。更新界面使用隔离浏览器和模拟状态验证，未运行真实安装程序。

设计与推广目录保留相应日期的资料和演示数据，不能据此认定真实服务器检查或外部投稿在本次执行。当前产品行为以 README 和本版本记录为准。

本版本不增加数据库 schema 迁移，也不自动部署远程服务端。
