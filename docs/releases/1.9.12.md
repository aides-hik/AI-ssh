# 1.9.12 升级说明

1.9.12 修复模型思考程度只能使用默认值的能力识别与参数适配问题。安装包见 [GitHub Release](https://github.com/aides-hik/AI-ssh/releases/tag/v1.9.12)，完整记录见 [更新日志](../../CHANGELOG.md)。

## 思考能力与档位

自定义兼容接口返回的实际思考档位会被保留；Ollama 刷新模型时读取思考级别或开关。缺少资料表示尚未识别，不代表模型一定不支持调整，也不会因此给所有模型发送未经确认的参数。

如果中转别名或自定义部署仍只有“默认”，请在“设置 → AI 服务商”展开该模型的“参数”，将“思考能力”改为“手动配置”。选择服务实际支持的参数格式和档位，点击“应用思考能力”，聊天中的思考滑块即可使用这些档位。也可声明仅支持思考开关。

手动设置仅属于当前模型，在刷新目录和重启后保留。切回“自动识别”恢复服务资料；选择“不提供调整”停止发送额外思考参数。终端中的思考选择仍可以临时覆盖模型默认档位。

## 接口与执行边界

- Ollama 原生接口使用 think，兼容接口使用 reasoning_effort，分别处理强度档位和布尔开关。
- Gemini 和 Responses 仅提供已适配的档位及格式；保存配置与当前原生接口不匹配时，界面会提示重新配置。
- 每次发送会复制配置及档位数组，执行期间修改设置不会改变本轮后续工具调用。

## 验证范围

桌面端 787 项自动化测试和 28 项独立浏览器场景通过，覆盖实际 HTTP 请求体的离线断言、配置保存与刷新、模型隔离、键盘操作、深浅主题和窄窗口。验证没有调用真实付费模型接口，不表示逐个服务商账号均已联调。

本版本无需数据库 schema 迁移。
