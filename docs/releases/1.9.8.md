# 1.9.8 升级说明

1.9.8 修复 AI 上下文、工具审批、聊天历史、应用更新和可选服务端登录会话。安装包从 [GitHub Release](https://github.com/aides-hik/AI-ssh/releases/tag/v1.9.8) 获取，平台与架构选择见 [项目介绍](../../README.md#下载与安装)。完整变更见 [更新日志](../../CHANGELOG.md)。

## 桌面端

- AI 长用户输入与系统上下文完整传递，历史压缩保留用户要求和已有摘要，并记录工具目标、参数、状态及结果。模型自身的上下文容量仍有限。
- “自动批准只读操作”关闭后，每次读取都需要确认，也不再自动读取服务器环境文档；自定义命令、部署及环境文档修改继续展示确切内容并等待确认。
- 聊天历史按连接身份在本机保存和恢复。条数限制只影响本机记录；关闭保存会清除已有历史。达到工具执行轮次上限时会提示任务未完成并保留进度，继续前请核对远程状态。
- 更新检查、测速和下载支持超时及取消；取消后可以重新检查，安装程序启动失败后可以重试。安装包通过临时文件下载并校验后提交。
- SSH 连接导入按主机、端口和用户名判断重复，保留同主机不同账号或端口。终端修复中文和表情跨数据块时的乱码。
- 环境文档读取和写入支持请求取消；最终提交开始后保留真实结果，停止后不再继续写入其他目标。

桌面端仍可独立运行，SSH、SFTP 与自定义模型无需注册账号或部署服务端。升级前备份本机数据的方法见 [数据存储说明](../../README.md#数据保存在什么地方)。

## 自托管服务端

本次服务端增加持久登录会话并启用正式 PostgreSQL 迁移。旧令牌不再接受，升级后需要重新登录；登出会同时撤销当前设备的访问与刷新令牌，其他设备会话不受影响。账号禁用和权限变更即时生效。Redis 异常时健康检查返回 HTTP 503。

全新空库可以直接执行版本迁移。已有数据库必须先备份、核对结构，并按 [PostgreSQL 迁移与已有数据库接入](../postgresql-migrations.md) 完成 baseline 接入；不要直接补跑 baseline SQL 或未经核对标记已应用。启动不再自动回退到 db push。
