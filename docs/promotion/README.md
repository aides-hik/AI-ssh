# 棱镜 Prism 推广资料

这套资料面向自己管理少量服务器的开发者、自托管爱好者和小团队技术负责人。统一介绍为“棱镜 Prism：把 SSH 终端、远程文件管理和 AI 助手放在同一窗口的桌面工作台”。

本目录同时保留 2026-10-26 至 2026-10-27 的投稿、邮件草稿和渠道核查记录。已提交内容与机器载荷保留当时原文，不代表当前渠道状态、费用或产品行为；复用前按各渠道页面和当前项目 README 核对。当前读取工具遵循“自动批准只读操作”设置，关闭后逐次确认。可复用的介绍模板见 `launch-copy.md`；历史投稿记录与未发送草稿不构成新的对外发送指令。

内容依据当前工作区的 [项目介绍](../../README.md) 和 [1.9.7 更新记录](../../CHANGELOG.md) 整理。2026-10-26 已核对 [v1.9.7 Release](https://github.com/aides-hik/AI-ssh/releases/tag/v1.9.7) 的 Windows、两种 macOS 架构、Linux AppImage 与 DEB 安装包及四个平台更新 manifest；后续发布时仍以下载页为准。

## 使用顺序

1. 按 [四周推广计划](./launch-plan.md) 完成第一轮试用和渠道验证。
2. 从 [各渠道介绍文案](./launch-copy.md) 选用相应内容；将实际发布链接记入 [渠道记录表](./channel-tracker.csv)。
3. 按 [演示视频脚本](./demo-script.md) 录制测试环境的真实操作；界面预览素材单独标明模拟数据。
4. 用 [试用反馈模板](./feedback-template.md) 记录首次连接、AI 任务和七日回访，集中修复主要卡点。
5. 按[新增投稿渠道](./submission-channels.md)选择下一步入口；该清单记录条件，各渠道实际提交状态见渠道记录表。
6. 新一轮平台文案见[各渠道定稿](./additional-submissions.md)，实际结果以渠道记录表及下方投稿记录为准。
7. 2026-10-27 新增两个中文周刊及产品目录材料见[第二轮投稿定稿](./round-two-submissions.md)，其中汇智网邮件另有[可打开的邮件草稿](./hubwiz-review-draft.eml)。

## 对外表述依据

- 桌面端的终端和文件功能无需注册或部署后端。AI 功能需要用户配置可用模型，费用取决于所选服务商。
- 可宣传 SSH、SFTP、AI 分析、多机巡检，以及按阶段确认的 Docker / Compose 部署；支持范围以当前项目介绍为准。
- 专用巡检和读取工具遵循“自动批准只读操作”设置，关闭后逐次确认；自定义命令、部署阶段和服务器环境文档修改先展示目标与执行内容，经确认后执行。避免概括成“所有操作都要确认”或“AI 自动完成任何部署”。
- 系统安全存储用于保护保存的凭据；使用外部模型时，对话和参与分析的终端输出会发给配置的模型服务。避免承诺“数据完全不出本机”。
- 首轮“20 人试用”“5 人七日回访并继续使用”是验证目标，目前没有相应业绩数据。
- 仓库许可证尚需维护者明确，文案不擅自标记 MIT 或承诺开源授权。
