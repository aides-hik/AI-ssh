# 棱镜 Prism 试用反馈模板

可通过 [GitHub Issues](https://github.com/aides-hik/AI-ssh/issues) 提交经过检查的反馈，也可在原邀请渠道自愿回复。Issue 内容会公开，发送前确认没有敏感信息。

无需提供密码、私钥、API Key、主机地址、用户名、完整终端日志或数据库。截图只保留相关界面，遮盖服务器列表、模型凭据及业务数据；如需说明报错，摘录最小范围并清理敏感内容。

## 首次试用

复制以下问题填写即可；不适用项可跳过。不需要填写真实姓名或联系方式。

```text

系统及版本（例如 Windows 11 / macOS / Linux）：
芯片或架构（知道时填写）：
从哪里知道 Prism（朋友 / B站 / 周刊 / 博客 / 其他）：
原本想完成什么任务（一句话，不写服务器地址）：

安装与启动：成功 / 未成功 / 尚未尝试
首次 SSH 连接：成功 / 未成功 / 尚未尝试

SFTP 浏览或传输：成功 / 未成功 / 尚未尝试

是否尝试 AI：是 / 否
模型来源：外部服务商 / 本地 Ollama / 其他
服务商和模型名称（可选，不提供 Key、私有服务地址或配置导出）：

如何确认任务结果（简述，不贴完整日志）：
```

AI 任务的“完成”以实际检查结果判断。例如巡检要收到所选主机的结果；部署要检查服务能否正常响应。单条命令退出码为零不代表服务健康。

## 七日回访

只回访首次试用已满七天、且同意接受回访的人。未回复不等于已放弃；未满七天暂不计入到期回访。

```text
首次试用后是否继续使用：是 / 否 / 暂无合适任务
最近一次使用距今多久：
最常用的一项功能或场景：
是否完成过一次 AI 任务：是 / 否 / 未尝试
原来用什么方式完成这件事：
继续使用或停止使用的主要原因：
最希望下一版改善的一件事：
```
