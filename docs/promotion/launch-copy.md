## 掘金 / CSDN 用户向介绍

### 标题

棱镜 Prism：把 SSH、文件管理和 AI 放进一个窗口

### 正文

自己管理几台服务器时，排查问题常常需要在终端、文件工具和 AI 对话之间来回切换：先查日志，再复制输出，请 AI 分析，回到终端执行命令，然后核对结果。机器一多，还要记住每段输出来自哪台主机。

棱镜（Prism）把 SSH 终端、SFTP 文件管理和 AI 助手放在同一窗口，希望把这些步骤连起来。它是桌面应用，安装后添加自己的服务器连接，就可以使用终端和文件管理，无需注册账号，也无需部署项目后端。

需要 AI 时，再配置自己的模型服务地址、API Key 和模型。也可以接入本地 Ollama；参与终端操作的模型需要支持流式输出和工具调用，具体能力取决于模型及接口。

**从一次日常巡检开始。**

先连接服务器，在助手输入区的“操作目标”中选择本次要检查的主机，再提出问题，例如：“检查这些服务器的 CPU、内存、磁盘和监听端口，按主机汇总结果，只做巡检。”专用巡检工具会读取目标状态，助手结合返回结果整理信息。你可以继续追问某台主机的异常，查看需要进一步核实的项目。

**执行前，看清目标和命令。**

专用巡检和读取工具遵循“自动批准只读操作”设置，关闭后逐次确认。涉及自定义命令、部署阶段或服务器环境文档修改时，应用会先展示确切的主机和执行内容，由用户确认后执行。这个区分很重要：在多机操作中，审核内容除了命令本身，还包括它将在哪台服务器运行。

**部署也需要实际验证。**

Docker / Docker Compose 部署可以按阶段审核，逐台执行，独立阶段最多三台并行。执行过程中可切换主机查看实时输出，复制日志或停止执行。部署和回滚步骤需要包含验证命令；一条命令退出成功，不能直接等同于服务已经健康。失败、停止和未执行的任务会分别保留状态，便于继续判断下一步。

文件操作则使用同一窗口中的 SFTP 管理器，可以浏览目录、上传和下载文件。终端支持多标签、快捷命令和命令补全。日常只用这些功能，也可以先不配置 AI。

连接、模型配置和偏好默认保存在本机，敏感凭据通过操作系统安全存储保护。使用外部模型时，对话内容和参与分析的终端输出会发送到所配置的模型服务；模型费用、额度和访问权限由该服务商决定。选择模型前，建议先明确自己准备发送哪些数据。

如果你正在管理个人项目或少量 VPS，可以先在测试环境中体验一次“连接 → 巡检 → 审核命令 → 检查结果”的流程。欢迎在 Issues 中告诉我：你用的操作系统、卡在哪一步，以及原本想完成什么任务。反馈中请移除密码、私钥、API Key 和业务敏感信息。
