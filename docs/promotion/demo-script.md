# 棱镜 Prism：85 秒演示视频脚本

目标观众：自己管理个人项目或少量 VPS 的开发者。

核心任务：在一个窗口中完成连接、巡检、审核命令和查看结果。

状态：可录制脚本，尚未录制。功能依据为当前仓库 README；实际回复、耗时和结果以录制时测试环境为准。

## 录制准备

使用专门的测试服务器和可公开展示的测试数据。两台主机即可，命名为“测试 Web 01”“测试 Web 02”，预先确认连接正常。主机名应真实对应录制环境，不提前填入虚构的异常或结果。

录制前完成模型配置和一次连接检查。画面不进入密码、私钥和 API Key 输入区域；关闭系统通知，清除含业务数据的终端历史。展示连接界面时只拍不含凭据的区域。

建议画面比例 16:9、分辨率 1920×1080，应用字体调至录屏中可读。全程显示小字“测试环境录制”。模型等待较长时可以加速或剪去等待，并在对应片段注明“等待过程已加速”或“等待片段已剪辑”，保留操作顺序和真实结果。

模型的真实输出可能变化。录制时根据实际返回结果解说；如果没有发现异常，就展示正常状态和各主机差异。一次失败可以重录，但不能拼接成未实际完成的成功流程。

## 实际输入

巡检提示词：

> 请对已选中的两台测试服务器做只读巡检：查看 CPU、内存、磁盘使用情况和监听端口，按服务器分别汇总结果与需要进一步核实的项目。不要修改配置，不要执行部署。

自定义命令提示词：

> 请在当前选中的这台测试服务器上执行 docker version 查看 Docker 版本。先展示目标主机和完整命令，等我确认后再执行；不要安装软件或修改配置。

字幕中的命令应与确认卡片中的实际命令一致。若模型请求额外检查或确认，保留对应流程，不按脚本强行省略。

## 如使用浏览器预览录制

浏览器预览适合展示 UI 与交互。服务器、模型回复和执行日志均来自内存模拟，不能证明真实 SSH 操作或模型能力。

若录制的是浏览器预览，应全程显示“界面流程演示 · 服务器 / AI / 输出为模拟数据”，开头旁白改为“这段展示棱镜的界面操作流程，服务器、AI 回复和输出均为模拟数据”。标题和简介也明确标注“界面演示”。其余旁白按可见交互介绍，不说“连接真实服务器”或以模拟异常作为真实案例。

不要将真实环境片段和模拟执行结果拼接成同一次任务。可以分别发布真实任务演示和模拟界面介绍，并清楚标注素材来源。
