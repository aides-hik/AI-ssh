# 【软件自荐】棱镜 Prism：集成 AI 助手和多服务器巡检的 SSH 桌面工作台

棱镜（Prism）集成 SSH 终端、SFTP 文件管理和 AI 助手，适合自己管理服务器的开发者。桌面端无需注册或部署后端；AI 可接自己的模型服务，或支持工具调用的本地 Ollama 模型。

支持多台已连接主机巡检，按主机汇总 CPU、内存、磁盘、服务和端口状态；Docker / Compose 部署按阶段确认，提供实时日志和验证步骤。专用巡检和读取工具直接执行，自定义命令及部署阶段确认后执行。

提供 Windows、macOS、Linux 安装包。模型费用由服务商决定；使用外部模型时，相关对话和终端输出会发送到该模型服务。
