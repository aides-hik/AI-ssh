GOOD TO KNOW

开始之前，
你可能想知道。

更多使用说明和当前实现细节，
都可以在项目文档中找到。

阅读项目文档
需要注册账号或部署后端吗？

不需要。桌面端的 SSH、SFTP 和自定义模型功能可独立使用。下载安装后，添加自己的服务器即可；AI 功能需要另行配置模型服务。

可以使用哪些 AI 模型？

可配置自己的模型服务，包括 OpenAI 兼容接口、Claude 原生 Messages，以及本地 Ollama。参与终端操作的模型需要支持流式输出和工具调用。具体可用模型、访问权限、额度和费用由所选服务决定。

查看模型配置说明 ↗

AI 会看到我的终端内容吗？

使用外部模型时，对话内容及参与分析的终端输出会发送到你配置的模型服务。请留意输出中是否包含敏感信息，并自行了解服务商的数据处理方式；也可配置本地 Ollama。

支持 SSH 私钥和 SSH Agent 吗？

支持。私钥可选择本地文件或填写路径，支持带口令的私钥；连接时读取原文件。macOS / Linux 的 SSH Agent 需要设置 SSH_AUTH_SOCK，Windows 默认连接 OpenSSH Agent 服务。

连接凭据和 API Key 保存在哪里？

连接与模型配置保存在本机应用数据中。SSH 密码、私钥配置、私钥口令及 AI API Key 通过操作系统安全存储加密后写入本地数据库；系统密钥环不可用时，不会回退为明文保存。连接与设置的 JSON 导出默认不包含凭据。系统保护与机器或系统用户相关，复制数据库不能替代跨设备凭据迁移。

了解存储与备份 ↗

助手会直接执行所有命令吗？

专用巡检和读取工具会直接执行。自定义命令、部署阶段及服务器环境文档修改会先展示确切目标与内容，确认后执行。部署和回滚包含验证命令；命令完成不等于服务健康，仍需查看实际验证结果。
