# 服务商图标

`sources.json` 按服务商 ID 记录本地文件与官方来源，核对日期为 2026-10-25。
素材来自品牌官网、官网引用的 CDN 或官方 GitHub 组织，保留原始颜色与造型。
界面从本地资源加载，不在运行时访问图标源站。多个同品牌服务复用同一素材。

侧栏与标题的入口图标由 Canva 生成，随后按其造型整理为适合小尺寸显示、随主题着色的矢量组件 `AiProvidersIcon.vue`。
原稿：[Open generated image](https://www.canva.com/M/MAHZAtQS1-0?utm_source=OC-AaBlKrqBJJNF&utm_campaign=agent_connector_create_image_asset_opened)。

自定义 OpenAI 兼容服务与浏览器演示模型使用通用符号。
历史配置 `skylark` 的目录说明与官网指向不一致，未取得能确认品牌归属的官方素材，使用中性的服务商入口符号。

官方品牌标志归各自品牌所有，用于识别对应服务商。
