# Interface font

The interface uses **ChillRoundM / 寒蝉半圆体**, version **1.805**.

- Project: https://github.com/Warren2060/ChillRound
- Release: https://github.com/Warren2060/ChillRound/releases/tag/v1.805
- Upstream archive: `ChillRoundM_v1.805.zip`
- Archive SHA-256: `197018fdce5436fc99d8874d32c5b4702b2cc595006d2d341fb3542b6b5779bd`
- `ChillRoundM-Regular.otf` is a byte-for-byte copy of the archive's `ChillRoundM.otf`.
- Font SHA-256: `2c8da065414e3cab951744f15c25b17a9ab4ae93e48def22004bc917550d1219`

This is the original static Regular (400) font, not a variable font. CSS uses
normal browser weight matching and synthesis for emphasized text. The complete
upstream character set is retained; system Chinese fonts remain as fallbacks for
characters outside that set. Terminal output and code keep their monospace fonts.

`ChillRound-OFL.txt` is copied unchanged from the archive's `LICENSE.txt`.
The desktop packaging configuration includes it at `licenses/ChillRound-OFL.txt`.
